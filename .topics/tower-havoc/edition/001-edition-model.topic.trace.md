# Edition Model

## Current Read

Tower Havoc is the mechanical game; Dieselpunk Edition is the first visual interpretation.

## Design Direction

Keep rules edition-independent. Editions may reskin architecture, weapons, faction names, illustration, and props without changing mechanical interfaces.

## Next Artifacts

Future editions should point back to the same mechanical rule branch unless an explicit new game version intentionally changes mechanics.
