# Core Game Rules

## Current Read

This branch owns the rules that directly govern setup, turns, actions, building, ammunition, attacks, fortification, collapse, and victory.

## Design Direction

Keep stable governing rules as Decisions, explicit branch/gate semantics as Conditions, and balance hypotheses visibly provisional until playtest Evidence exists.

## Next Artifacts

Extend this branch with Evidence-backed Decisions when actual play changes a rule. Do not rewrite old Decisions to pretend later balance knowledge existed earlier.
