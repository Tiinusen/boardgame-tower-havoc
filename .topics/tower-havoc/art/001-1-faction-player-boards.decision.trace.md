# Approved Faction Player Boards

## Decision

- State: accepted next-playtest visual baseline
- Layout Invariant: all six boards use the same resource, floor, reinforcement, bell, and integrated quick-reference positions
- Mechanical Invariant: faction artwork does not alter gameplay
- Resource Wells: Ready Ammo; Production; Available Actions
- Floor Rows: three; each contains two Build slots and four Reinforcement slots labelled 2, 3, 4, 5
- Bell State: one persistent Bell construction slot; Ring the Bell has no separate physical slot
- Quick Reference: integrated into the board artwork; no separate quick-reference card
- Approved Visual Variants: Ironclads; Brass Union; Ember Rail; Storm Foundry; Ash Dominion; Horizon Guild
- Decision: use these six exact faction-board images as the next TTS visual baseline.

## Basis

The project Steward explicitly approved all six generated faction-board variants after reviewing their fixed layout, integrated reference text, and common slot grammar.

## Consequences

TTS may assign one approved board image per seat/faction. No faction-specific token art is required. Any future board variant must preserve the same gameplay layout unless a successor component Decision changes that layout first.

## Review Conditions

Physical print dimensions, bleed, and manufacturing tolerances remain outside this approval.
