# Mechanical equivalence across faction cosmetics

This artifact records the operative Tower Havoc state for this bounded subject.

## Decision

- State: accepted
- Component Rule ID: components.mechanical-equivalence
- Decision: Every faction tower-floor variant must preserve the same outer bounding box, footprint, floor-to-floor contact area, stacking height, alignment behavior, practical stability envelope, reinforcement interface locations, and accessibility. Cosmetic variation must not create a gameplay advantage.

## Basis

Physical asymmetry can accidentally change tower stability or handling even when written rules are symmetric.

## Consequences

Fusion 360 work begins from one mechanically neutral master. Cosmetic faction variants derive from that master only after stacking/handling tests.
