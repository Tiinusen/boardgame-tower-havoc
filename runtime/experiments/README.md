# Runtime schema experiments

These files are review candidates, not canonical Tiinex Docs authority.

The match-lineage example under `examples/match-lineage-demo/` pretends these
semantics already exist so their fit can be inspected before deciding whether
to land anything in Tiinex/docs or the Tower Havoc local schema family.

- `tiinex.human.runtime.v1.schema.candidate.md` explores a human-executed sibling to Machine Runtime.
- `towerhavoc.rule.resolution.v1.schema.candidate.md` explores automatic deterministic game-rule resolution independent of whether a human or machine performs the procedure.
